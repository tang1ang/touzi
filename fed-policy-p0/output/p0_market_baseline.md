## 1. P0 口径

| 项目 | 定义 |
| --- | --- |
| 预测对象 | 下一次 FOMC 的降息 / 维持 / 加息三分类概率，并外推未来四次会议路径 |
| 合约 | CME 30-Day Fed Funds Futures (ZQ)，以月度平均 EFFR 结算 |
| 利率基准 | 当前取 EFFR = 3.8800%；EFFR 无法使用时回退目标区间中值 |
| 决议生效 | 决议日当天仍按旧利率计息，**次一自然日**生效 |
| 合约映射 | 会议所在月份的 ZQ 合约（如 2026-12 → ZQZ26） |
| 步长 | 25 bp |
| 分解优先级 | 次月无政策会议时用次月合约；否则用当月合约按生效日拆分日权重 |
| 最少会后天数 | 7 天；低于该值时可靠性下调 |

隐含利率与日权重分解：

```text
r_month = 100 - 期货收盘价
r_post  = (r_month × D_month - r_pre × D_pre) ÷ D_post
```

概率把预期变动映射到 25bp 网格：`x = (r_post - r_pre) / 0.25`，在 `floor(x)` 与 `ceil(x)` 两档上按线性权重分摊，再聚合为降息 / 维持 / 加息。当 `|x| ≤ 1` 时，等价于 `P(hike)=clamp(x,0,1)`、`P(cut)=clamp(-x,0,1)`。

## 8. 限制与下一阶段

- ZQ 以月度平均 EFFR 结算；会前天数沿用当前 EFFR，未对月内资金面波动建模。
- 行情来自 Barchart 第三方延迟数据，非 CME 直连，仅用于 P0 基准。
- ZQ 最小价格变动 0.005，对应 0.5bp 利率精度；日权重分解会放大该误差。
- 月末会议会后天数很少时，优先使用次月干净合约，避免反推放大。
- 2027-10-26/27 为货币政策战略会议，不含利率决议，已排除出政策路径。
- P0 只给出市场隐含先验，尚未叠加宏观反应函数与美联储沟通文本信号。

P0 只回答“市场当前如何定价”。P1 将在此先验上叠加宏观反应函数（通胀、就业、金融条件）与美联储沟通文本信号，形成可解释的联合概率。
