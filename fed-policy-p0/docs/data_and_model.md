# 数据与预测逻辑说明

本文说明项目依赖的每一类数据、字段含义，以及从原始数据到「加息 / 维持 / 降息」概率的完整推理链。对应代码在 `fedp0/`（市场定价）、`fedp1/`（宏观、文本、P2 合成）与 `run_live.py`（实时入口）。

## 1. 系统总览

系统把三类信息合成一个三分类概率：

```text
FOMC 日历 ───────────────┐
ZQ 联邦基金期货 ──> 市场先验 ─┤
目标区间 / EFFR ──────────┘
                            ├──> P2 锚定合成 ──> 概率校准 ──> 幅度 ──> 输出
FRED 宏观序列 ──> 宏观信号 ─┤
FOMC 声明文本 ──> 文本信号 ─┘
ALFRED vintage ──> 仅用于回测训练
```

两种运行模式：

| 模式 | 入口 | 训练样本 | 预测时点 | 宏观数据 |
|------|------|----------|----------|----------|
| 回测 | `run_backtest.py` | 逐会议 expanding window | 决议日前 7 天 | 优先 ALFRED vintage |
| 实时 | `run_live.py` | 全部已完成会议 | 运行日 `as_of` | 当前可见数据 |

符号约定：**宏观分数与文本分数 > 0 表示鹰派（收紧倾向），< 0 表示鸽派（宽松倾向）**。

## 2. 数据字典

### 2.1 会议日历

| 数据 | 文件 | 含义 | 用途 |
|------|------|------|------|
| FOMC 会议日历 | `data/fomc_calendar.json` | 每次会议的决议日 `decision_date`、生效日 `effective_date`、类型 `policy` / `notation vote` | 确定预测目标、合约月份、会前/会后天数 |

`notation vote` 不是政策决议会议，不进入训练与预测。决议日公布决定，生效日通常为次日，利率自生效日起计息。

### 2.2 市场数据

| 数据 | 文件 | 频率 / 单位 | 具体含义 | 模型中用途 |
|------|------|-------------|----------|------------|
| ZQ 联邦基金期货 | `data/backtest/zq_history.csv`；`data/market/zq_curve_*.csv` | 日频；价格点 | 30 天联邦基金利率期货收盘价。报价为 `100 - 隐含平均联邦基金利率`，例如 96.10 表示 3.90% | 计算市场隐含的会后利率、三分类概率、预期幅度 |
| 目标区间上限 | `data/backtest/rates_long.csv` 的 `DFEDTARU` | 日频；% | FOMC 目标区间上限 | 判断实际决议是加息 / 维持 / 降息 |
| 目标区间下限 | 同上 `DFEDTARL` | 日频；% | FOMC 目标区间下限 | 记录区间；实际方向以区间上限变化为准 |
| 有效联邦基金利率 | 同上 `EFFR` | 日频；% | 银行间隔夜联邦基金实际成交利率 | 作为会前利率基准 `pre_rate` |

实际决议标签：

```text
delta = 生效日 DFEDTARU - 决议日 DFEDTARU
delta > 0 -> hike；delta < 0 -> cut；delta = 0 -> hold
```

### 2.3 宏观数据（FRED）

所有序列保存在 `data/macro/raw/{SERIES}.csv`，字段为 `observation_date,value`；`data/macro/metadata.json` 记录来源、最新观测与抓取时间。

| 序列 | 名称 | 频率 / 单位 | 具体含义 | 模型中的用途 |
|------|------|-------------|----------|--------------|
| `PCEPILFE` | 核心 PCE 价格指数 | 月频；指数 | 剔除食品与能源的个人消费支出价格指数，美联储最看重的通胀指标 | 同比、3 个月年化；通胀评分与 Taylor 规则的通胀项 |
| `CPILFESL` | 核心 CPI | 月频；指数 | 剔除食品与能源的消费者物价指数 | 3 个月年化；作为通胀的交叉验证 |
| `UNRATE` | 失业率 | 月频；% | U-3 失业率 | 与自然失业率比较，得到失业率缺口 |
| `NROU` | 自然失业率 | 季频；% | CBO 估计的长期非加速通胀失业率 | 失业率缺口 = UNRATE - NROU；再按 Okun 系数推产出缺口 |
| `PAYEMS` | 非农就业人数 | 月频；千人 | 企业调查口径的非农就业总量 | 3 个月平均新增就业，与 10 万人盈亏平衡线比较，得到就业动量 |
| `GDPC1` | 实际 GDP | 季频；十亿美元（2017 链式美元，季调折年） | 剔除通胀后的实际产出 | 季度环比折年率与同比；增长评分 |
| `NFCI` | 芝加哥联储全国金融条件指数 | 周频；标准差 | 0 表示平均金融条件，正值表示比平均更紧，负值表示更松 | 金融条件评分；水平值进入模型，4 周变化仅记录 |
| `BAMLH0A0HYM2` | 美国高收益债期权调整利差 | 日频；% | ICE BofA 高收益债相对国债的信用利差，越高表示信用环境越紧 | 信用利差评分；2023-11-21 起可用 |
| `BAA10Y` | Moody's Baa 与 10 年国债利差 | 日频；% | 长期历史可用的信用利差替代指标 | 高收益 OAS 不可用时回退使用 |
| `DGS2` | 2 年期美债收益率 | 日频；% | 2 年期国债的固定到期收益率 | 记录水平与 1 个月变化，用于交叉验证，不直接进入评分 |
| `DGS10` | 10 年期美债收益率 | 日频；% | 10 年期国债的固定到期收益率 | 记录水平，用于交叉验证，不直接进入评分 |
| `T10YIE` | 10 年期盈亏平衡通胀率 | 日频；% | 10 年期名义国债与 TIPS 的收益率差，代表市场长期通胀预期 | 记录水平，用于交叉验证，不直接进入评分 |

注意：`DGS2`、`DGS10`、`T10YIE` 目前只作为特征记录，不直接进入宏观综合分；这是为了避免与 ZQ 市场定价重复计入利率信息。

### 2.4 文本数据

### 2.5 实时修订数据（ALFRED vintage）

| 文件 | 含义 |

历史长表 `zq_history.csv` 可能缺少最近上市的新合约；实时预测会用最新一份 `zq_curve_*.csv` 补齐缺失合约，并在 `manifest.json` 中记录该快照路径。

## 3. 时间对齐与无前视规则

### 3.1 回测时点

每次会议的回测预测时点：

```text
T = decision_date - 7 天
```

只允许使用 `T` 当日或之前可见的数据：

- 市场行情：取 `T` 之前最近一个收盘价；
- 利率：取 `T` 之前最近一个观测；
- 声明：只使用 `T` 之前已发布的声明；
- 宏观：优先取 `T` 当日或之前最近的 ALFRED vintage；没有 vintage 时，使用当前版本并叠加发布滞后。

### 3.2 发布滞后（无 vintage 时的回退）

| 序列 | 滞后天数 | 序列 | 滞后天数 |
|------|----------|------|----------|
| `PCEPILFE` | 55 | `GDPC1` | 110 |
| `CPILFESL` | 40 | `NROU` | 120 |
| `UNRATE` | 35 | `NFCI` | 7 |
| `PAYEMS` | 35 | `BAMLH0A0HYM2` / `BAA10Y` | 1 / 0 |
| `DGS2` / `DGS10` / `T10YIE` | 0 | | |

含义：例如 `T` 为某月 20 日，核心 PCE 只使用 `T - 55 天` 之前发布的观测，避免把尚未公布的数据算进去。

### 3.3 实时新鲜度门控

实时模式按“观测日期年龄”检查数据是否过期：

| 数据 | 最大年龄 | 说明 |
|------|----------|------|
| ZQ 行情 | 3 天 | 超过则列入 `stale_sources` |
| 利率 `DFEDTARU/L`、`EFFR` | 7 天 | `EFFR` 过期视为关键过期 |
| FOMC 声明 | 60 天 | 超过则提示 |
| `PCEPILFE` | 100 天 | 已考虑月末与发布滞后 |
| `CPILFESL` / `UNRATE` / `PAYEMS` | 75 天 | 月度序列，按发布周期放宽 |
| `GDPC1` | 150 天 | 季度序列 |
| `NROU` | 120 天 | 季度序列 |
| `NFCI` | 10 天 | 周频 |
| 日频市场序列 | 5 天 | 周末与假期容忍 |

`--fail-on-stale` 时，如果市场行情或 `EFFR` 关键数据过期，程序直接报错，不输出预测。

## 4. 市场先验：ZQ 期货 → 三分类概率

### 4.1 报价转利率

```text
隐含利率 r = 100 - ZQ 收盘价
```

### 4.2 估计会后利率

对每次会议，优先使用“次月没有政策会议”的干净合约：

- 若下个月没有 FOMC 政策会议，则下月合约的隐含利率就是会后利率；
- 否则，用会议当月合约按天拆分：

```text
r_post = (r_month × D - r_pre × D_pre) / D_post
```

其中 `D` 为当月天数，`D_pre = effective_date.day - 1` 为会前天数和，`D_post = D - D_pre` 为会后天数。

可靠性：

```text
放大倍数 = D / D_post
估计噪声 = 放大倍数 × 1bp
噪声 ≤ 2bp -> high；≤ 5bp -> medium；> 5bp -> low
```

### 4.3 三分类概率

把会后利率相对会前利率的变化 `delta = r_post - r_pre` 映射到 25bp 步长网格：

```text
x = delta / 0.25
lo = floor(x)，hi = lo + 1
w_hi = clip(x - lo, 0, 1)
```

把权重分配到 `lo` 与 `hi` 两个整数步长结果上，再按 `<0 / =0 / >0` 聚合成：

```text
cut  = 负步长结果权重之和
hold = 0 步长结果权重
hike = 正步长结果权重
```

当 `|delta| ≤ 25bp` 时，等价于：

```text
P(hike) = clip(delta / 0.25, 0, 1)
P(cut)  = clip(-delta / 0.25, 0, 1)
```

该方法允许一次会议出现多步变动（如 50bp），但最终仍聚合为三类。

## 5. 宏观信号

### 5.1 特征构造

| 特征 | 计算 | 含义 |
|------|------|------|
| 核心 PCE 同比 | 最新值 / 一年前值 - 1 | 通胀水平 |
| 核心 PCE 3 个月年化 | `(最新/3个月前)^(365/天数) - 1` | 通胀短期动量 |
| 核心 CPI 3 个月年化 | 同上 | 通胀交叉验证 |
| 失业率缺口 | `UNRATE - NROU` | 负值表示劳动力市场偏紧 |
| 非农 3 个月平均 | `(最新 - 3个月前) / 3` | 就业动量，单位千人/月 |
| GDP 环比折年率 | `(最新/上期)^4 - 1` | 增长相对潜在增速 |
| NFCI | 最新水平 | 正值 = 金融条件偏紧 |
| 信用利差 | 高收益 OAS 或 Baa-10Y | 越高 = 信用条件越紧 |

### 5.2 分项评分

所有 `scale(x, center, half_width) = clip((x - center) / half_width, -1, 1)`。

```text
通胀评分 = clip(
    0.5 × scale(核心PCE同比, 2.0, 1.0)
  + 0.3 × scale(核心PCE 3m年化, 2.0, 1.0)
  + 0.2 × scale(核心CPI 3m年化, 2.0, 1.0)
)

就业动量 = scale(非农3m平均, 100, 100)
就业评分 = clip(
    0.7 × scale(-失业率缺口, 0.0, 0.5)
  + 0.3 × 就业动量
)

增长评分 = scale(GDP环比折年率, 1.8, 2.0)

金融条件评分 = clip(
    0.6 × (-scale(NFCI, 0.0, 0.5))
  + 0.4 × (-scale(信用利差, 中枢, 半宽))
)
```

信用利差参数：

- 高收益 OAS：中枢 4.0%，半宽 2.0%；
- Baa-10Y：中枢 2.0%，半宽 1.0%。

### 5.3 Taylor 规则与目标利率

```text
产出缺口 = -2 × 失业率缺口          # Okun 系数 2
Taylor 利率 = 0.5 + 核心PCE同比
            + 0.5 × (核心PCE同比 - 2.0)
            + 0.5 × 产出缺口

宏观目标利率 = Taylor 利率
             + 0.10 × 就业动量
             + 0.25 × 金融条件评分
```

其中 `0.5` 是实际中性利率 `r*`，`2.0` 是通胀目标。

政策缺口与综合分：

```text
政策缺口(bp) = (当前利率 - Taylor 利率) × 100
Taylor 信号 = clip(-政策缺口 / 50)

综合分 = clip(
    0.5 × Taylor 信号
  + 0.2 × 通胀评分
  + 0.1 × 就业评分
  + 0.1 × 增长评分
  + 0.1 × 金融条件评分
)
```

说明：宏观三分类概率由 5.4 节的宏观路径生成，综合分主要用于解释各分项方向与报告展示，不直接映射为概率。

直观理解：

- 当前利率低于 Taylor 利率 → 政策偏松 → `Taylor 信号 > 0` → 偏鹰；
- 通胀高于 2% → 通胀评分为正；
- 失业率低于自然失业率 → `-失业率缺口 > 0` → 劳动力市场偏紧；
- GDP 高于潜在增速 → 增长评分为正；
- NFCI 或信用利差偏高 → 金融条件评分为负 → 偏鸽。

### 5.4 宏观路径

从当前利率出发，逐次会议向宏观目标利率收敛：

```text
gap  = 目标利率 - 当前利率
move = clamp(gap × 0.25, -0.25, +0.25)
会后利率 = 当前利率 + move
```

`0.25` 是收敛速度，`±0.25` 是单次会议最大变动 25bp。再由 `move` 走第 4.3 节的三分类映射，得到宏观概率。

## 6. 文本信号

### 6.1 鹰鸽词典

`fedp1/text.py` 内置可复现的短语词典：

- 正权重 = 鹰派，例如 `inflation remains too high`（+2.6）、`further tightening`（+2.0）；
- 负权重 = 鸽派，例如 `cut the target range`（-2.6）、`labor market has cooled`（-1.5）。

匹配时优先最长短语；如果短语前 4 个词出现否定词（`not`、`no`、`never` 等），权重乘以 `-0.7`，避免“不会进一步收紧”被误判为鹰派。

原始分归一化：

```text
词典分 = clip(raw / (总绝对权重 + 2.0), -1, 1)
```

### 6.2 单份声明评分

去掉政策动作句和异议句后计算词典分，再叠加结构化信息：

```text
动作分：raise/increase = +1，maintain = 0，lower/cut = -1
异议分 = clip((鹰派异议票数 - 鸽派异议票数) × 0.25, -1, 1)

声明分 = clip(0.6 × 词典分 + 0.2 × 动作分 + 0.2 × 异议分)
```

### 6.3 声明 diff

比较最近两份声明的句子集合：

- 新增句子的词典分 `added_score`；
- 删除句子的词典分 `removed_score`；
- `diff_score = clip(added_score - removed_score)`。

含义：新增鹰派措辞或删除鸽派措辞 → diff 为正；反之亦然。

### 6.4 P2 文本总分

P2 使用声明、diff 和异议票：

```text
异议分 = clip((鹰派异议票数 - 鸽派异议票数) / 3, -1, 1)

文本总分 = clip(
    0.45 × 声明分
  + 0.45 × diff_score
  + 0.10 × 异议分
)
```

文本三分类概率：

```text
logits = [-2.0 × 文本总分, 0, +2.0 × 文本总分]   # 对应 cut / hold / hike
概率 = softmax(logits)
```

文本总分为正 → 加息 logit 更高 → 偏鹰。

## 7. P1 合成（对照模型）

P1 在 log-odds 空间合成市场、宏观、文本：

```text
市场 logit = log(市场概率)
文本 logit = [市场 cut logit - 2×文本分,
              市场 hold logit,
              市场 hike logit + 2×文本分]

合成 logit = w_market × 市场 logit
           + w_macro  × 宏观 logit
           + w_text   × 文本 logit

概率 = softmax(合成 logit)
```

默认权重 `(0.60, 0.25, 0.15)`；文本权重随会议期限按 `0.5^(i-1)` 衰减，市场权重不低于 0.5。若合成概率与市场偏离超过 15pp，`review_flag = true`。

P1 只用于与 P2 对照，不是当前实时主模型。

## 8. P2 主模型

### 8.1 市场锚定

P2 以市场概率为锚，只有在以下条件全部满足时才允许偏离：

1. 偏离强度 `blend > 0`；
2. 市场定价可靠性不是 `low`；
3. 市场没有接近确定：最大类别概率 `< 0.80`，且 `max(hike, cut) < 0.80`；
4. 宏观方向与文本方向一致，且都不为 0；
5. 市场方向与宏观方向不同（市场方向由 `hike - cut` 超过 ±0.05 判定）。

满足后：

```text
pooled = log-odds 池化(市场, 宏观, 文本, 权重)
delta  = clip(pooled - 市场, -12pp, +12pp)
raw    = normalize(市场 + blend × delta)
```

默认：

```text
权重 = (市场 0.85, 宏观 0.10, 文本 0.05)
blend = 0
```

`blend = 0` 时 `raw` 严格等于市场概率，P2 不会主动发表与市场相反的判断。

### 8.2 Walk-forward 超参数选择

回测逐会议向前推进，只用当前会议之前已经完成的会议选择：

- 权重网格：`(0.85,0.10,0.05)`、`(0.75,0.15,0.10)`、`(0.65,0.20,0.15)`、`(0.55,0.25,0.20)`；
- 偏离强度网格：`0, 0.25, 0.5, 0.75, 1.0`；
- 目标：最小化历史会议的 log loss；
- 只有相对默认参数改善超过 `0.005` 才采用新参数，否则回退默认。

### 8.3 概率校准

对 `raw` 概率有三种候选校准：

| 方法 | 做法 |
|------|------|
| `raw` | 不校准 |
| `shrinkage` | 向训练期基础频率收缩：`(1-α) × raw + α × base`，α 从 0 到 0.6 选择 |
| `platt` | 分别对 hike、cut 的概率做 logit 后的 Platt 缩放：`sigmoid(a × logit(p) + b)`，再归一化 |

选择方式：比较三种方法在历史会议上的样本外 log loss；只有优于 `raw` 超过 `0.002` 才采用校准。校准器选择至少需要 8 次样本；Platt 拟合本身至少需要 10 次，样本不足时 Platt 内部退回恒等映射。

`platt` 的 `a` 限制在 `[0.25, 4.0]`，`b` 限制在 `[-2.0, 2.0]`，并带 L2 正则向恒等映射收缩。

### 8.4 幅度预测

三种候选：

| 方法 | 含义 |
|------|------|
| `identity` | 直接使用市场隐含变动 `market_bp` |
| `linear` | 用历史数据拟合 `actual_bp = intercept + slope × market_bp`，再向恒等映射收缩 |
| `class` | 用三分类概率的期望步长：`(P(hike) - P(cut)) × 25bp` |

选择方式：比较历史会议的 MAE；只有优于 `identity` 超过 `0.5bp` 才采用其他方法。样本少于 6 次时强制 `identity`。

### 8.5 实时拟合

`run_live.py` 的流程：

1. 取 `as_of` 之前已完成、且实际决议数据可用的会议作为训练集；
2. 用训练集选择权重、`blend`、校准器和幅度方法；
3. 用训练期残差的 10% / 90% 分位构造幅度区间；
4. 对 `as_of` 之后的未来会议，用当前市场路径和当前宏观/文本信号生成预测；
5. 输出市场概率、`raw`、校准后概率、edge 分解、幅度和提示。

### 8.6 输出字段

| 字段 | 含义 |
|------|------|
| `market.probability` | ZQ 市场隐含概率，未校准 |
| `raw_probability` | 锚定合成后的原始概率；`blend=0` 时等于市场概率 |
| `calibrated_probability` | 最终 P2 概率 |
| `edge_pp` | `calibrated - market`，对市场的概率差 |
| `anchor_edge_pp` | `raw - market`，方向性偏离；`blend=0` 时为 0 |
| `calibration_shift_pp` | `calibrated - raw`，校准带来的抬升或压低 |
| `most_likely` | 校准后概率最大的类别 |
| `market_most_likely` | 市场概率最大的类别 |
| `direction_flip_by_calibration` | 校准是否把判断从市场方向翻转 |
| `magnitude_bp` | 预期变动，单位 bp |
| `magnitude_interval_bp` | 训练残差的 10%-90% 区间 |
| `action_hint` | 对 edge 来源、接近确定、方向翻转的提示 |
| `data_quality.freshness` | 各数据源最新日期与是否过期 |
| `data_quality.inputs` | 输入文件路径、大小与 sha256 |
| `model` | 本次使用的权重、`blend`、校准器、幅度方法 |
| `training` | 训练起止、样本数与训练指标 |

关键读法：

```text
若 anchor_edge_pp ≈ 0 且 edge_pp 明显非 0：
    edge 来自校准，不是宏观/文本发现的方向性机会。
```

## 9. 当前表现与正确解读

截至 2026-11-22 的 P2 回测（2021-01 至 2026-10，47 次会议）：

| 模型 | 准确率 | Brier | Log loss |
|------|--------|-------|----------|
| 市场 | 100% | 0.0303 | 0.0691 |
| P1 | 95.7% | 0.0702 | 0.1415 |
| P2 | 100% | 0.0253 | 0.0549 |

幅度：MAE 2.85bp，RMSE 5.72bp。预测截止日 7 / 14 / 30 天的 Brier 分别为 0.0253 / 0.0171 / 0.1032，30 天准确率 93.6%。

必须注意：

- P2 与市场方向 47/47 一致，主动偏离 0 次，`blend=0`；
- P2 的改进主要来自概率校准，不是独立的宏观/文本 alpha；
- 样本以“维持”和“加息”为主，类别不平衡，100% 准确率不能外推为稳定优势；
- 实时输出中若 `edge_pp` 很大但 `anchor_edge_pp` 为 0，应视为校准效应，不能直接当作交易信号。

## 10. 已知局限

1. **行情源**：ZQ 为第三方延迟日线，不是 CME 实时结算价；历史长表可能缺新合约，需要静态快照补齐。
2. **刷新依赖**：`--refresh` 的 ZQ 步骤依赖 Node + puppeteer-core，当前环境未安装；其余宏观/利率/声明数据可刷新。
3. **校准偏差**：Platt 在小样本上可能把 90% 抬到 98%，甚至把 hold 翻成 hike；输出已用 `calibration_shift_pp` 和 `direction_flip_by_calibration` 标记。
4. **数据修订**：实时预测使用当前修订值；回测使用 vintage。两者口径不同，比较时需注意。
5. **文本覆盖**：P2 只使用声明与 diff，不使用演讲、SEP、点阵图和发布会问答。
6. **样本量**：47 次会议，无法稳定估计复杂的非线性关系；当前模型保持规则化与低参数。
7. **不构成投资建议**：尚未加入仓位、成本、滑点和纸面交易验证。
